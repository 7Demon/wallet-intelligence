Engine First, Dashboard Last

Fokus utama adalah akurasi rekonsiliasi data dan auditability. Integritas saldo dan kalkulasi PnL menjadi prioritas di atas estetika semata.

2

Kebenaran di Atas Asumsi

Jika transaksi multi-hop atau DEX baru tidak dikenali polanya, engine menandainya sebagai UNKNOWN untuk diinspeksi, daripada menebak secara keliru.

3

100% Reproducibility

Payload mentah disimpan permanen di basis data PostgreSQL. Ketika parser ditingkatkan, seluruh riwayat transaksi dapat diproses ulang tanpa query RPC baru.

4

Lean Zero-Cost Architecture

Dapat dijalankan secara efisien tanpa memerlukan infrastruktur mahal seperti Kafka, ClickHouse, atau kluster server rumit. Cukup FastAPI, PostgreSQL, dan Next.js.

1. Ingestion & Persistensi

2. Deterministic Parsing

TAHAP 1: RPC BATCH INGESTION workers/fetcher/solana_client.py

Pengambilan Data Transaksi Skala Besar dengan Batching

Engine memanggil getSignaturesForAddress untuk mengambil daftar signature, kemudian mengirim batch hingga 25 instruksi secara paralel melalui getParsedTransactions. Jika node RPC mengembalikan kode 429 (Rate Limit), client melakukan jeda eksponensial (exponential backoff).

// Cuplikan Pemanggilan JSON-RPC Batch client = SolanaClient(rpc_url) signatures = await client.get_signatures_for_address(wallet_address, limit=100) raw_txs = await client.get_parsed_transactions_batch(signatures[0:25])

Matriks Klasifikasi Trader (Rule Matrix)

Sistem pelabelan 4-dimensi objektif yang dikonfigurasi melalui JSON terisolasi.

config/classification_thresholds.json
1. Performance
HIGHLY_PROFITABLE

ROI ≥ 100% & Win Rate ≥ 60%

PROFITABLE

ROI ≥ 20% & Win Rate ≥ 50%

BREAK_EVEN

-20% ≤ ROI ≤ 20%

UNPROFITABLE

ROI < -20%

2. Trading Style
SCALPER

Median Hold ≤ 5 Menit

SHORT_TERM_TRADER

5 Menit < Median Hold ≤ 2 Jam

SWING_TRADER

2 Jam < Median Hold ≤ 3 Hari

HOLDER

Median Hold > 3 Hari

3. Capital Tier
MICRO

Rata-rata posisi < $100

SMALL

$100 ≤ Rata-rata < $1,000

MEDIUM / LARGE

$1,000 s/d $100,000

VERY_LARGE (WHALE)

Rata-rata posisi ≥ $100,000

4. Activity Level
INACTIVE

0 trade dalam 30 hari

OCCASIONAL

< 1 trade per hari

ACTIVE

1 s/d 10 trade per hari

HIGH_FREQUENCY

> 10 trade/hari (Bot / Scalp)

Panduan Pengembang (Change Map)

Gunakan panduan singkat ini untuk menavigasi kode sumber ketika ingin menambahkan fungsionalitas baru ke dalam sistem:

Menambah DEX Baru:

Daftarkan Program ID di workers/parser/swap_detector.py

Mengubah Batas Lencana:

Edit aturan ambang di config/classification_thresholds.json

Menambah Quote Token:

Daftarkan mint address di workers/parser/swap_detector.py

Menjalankan Pengujian:

Jalankan perintah pytest pada root proyek
